*   스크린샷 캡처 시 시각적 오프셋이 발생하는 문제 수정.
*   APE 병렬 디코딩에서 앵커 포인트(Anchor point) 인식 이상 문제 수정.
*   일괄 처리 중 APE 파일에 대해 무한 루프를 유발할 수 있는 취약점 수정.

*   Linux 플랫폼에서 작업 공간 전환 시 재생이 차단되는 문제 수정.
*   일괄 처리 중 예외 발생 시 나타나는 영구적인 교착 상태(Deadlock) 문제 수정.
*   작업을 중지하거나 애플리케이션을 종료할 때 발생하는 메모리 액세스 위반 크래시 수정.

*   JPEG 이미지 인코더의 잠재적인 메모리 누수 수정.
*   재생 중 오디오 출력 장치 연결이 해제될 때 발생하는 기본 API 접근 위반 수정.
*   창이나 컨트롤의 크기가 실제로 변경되지 않았을 때 발생하는 무한 레이아웃 응답 루프 문제 수정.
*   일괄 처리 비동기 쓰기 대기열의 수명 주기 및 백프레셔(Backpressure) 동기화 문제 수정.
*   단측(Single-sided) 푸리에 변환에 양측(Double-sided) 에너지 보상이 누락되어 전체적인 스펙트럼 에너지 계산이 낮아지는 문제 수정.
*   FFmpeg 사용자 지정 I/O 스트림의 부적절한 정리로 인해 발생하는 심각한 메모리 누수 및 이중 해제(Double-free) 문제 수정.
*   이미지 내보내기 중 창을 전환하거나 닫을 때 백그라운드 비동기 스레드가 허상 포인터(Dangling pointer)를 참조하여 발생하는 크래시(Crash) 문제 수정.
*   유니코드 경로 지원 부족으로 인해 Windows 환경에서 TIFF 및 JPEG 2000 형식으로 내보낼 때 저장이 실패하는 문제 수정.
*   Windows 환경에서 마우스 커서를 포함하여 스크린샷을 캡처할 때, 기본 API 반환값에 대한 유효성 검사 누락으로 발생할 수 있는 메모리 범위 초과(Out-of-bounds) 크래시 문제 수정.
*   부적절한 OpenGL 컨텍스트 형식 초기화 타이밍으로 인해 GPU 하드웨어 가속 환경에서 스펙트럼 오버레이가 잘못 표시되는 문제 수정.
*   일괄 처리 작업 정리 중 파괴된 객체의 허상 포인터에 접근하여 발생하는 힙 메모리 손상 및 애플리케이션 크래시 문제 수정.
*   I/O 스레드 초기화 중 발생하는 메모리 누수 수정.
*   일괄 처리 중 UI 버튼을 비활성화하는 순차적 논리 오류 수정.
*   스캔 단계에서 일괄 처리 작업을 일시 중지, 재개 또는 종료할 수 없는 문제 수정.
*   일괄 처리 중 출력 경로 계산 오류 수정.
*   일괄 처리 뷰가 스페이스바에 잘못 반응하는 문제 수정.

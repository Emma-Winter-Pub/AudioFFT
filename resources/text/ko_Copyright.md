### 핵심 라이브러리 및 이미지 인코딩 라이브러리

**Qt 6**
* 용도: 그래픽 사용자 인터페이스(GUI) 및 크로스 플랫폼 프레임워크
* 라이선스: GNU LGPL 버전 3

**FFmpeg**
* 용도: 오디오 디코딩 및 멀티미디어 스트림 처리
* 라이선스: GNU LGPL 버전 2.1 이상

**FFTW3**
* 용도: 고속 푸리에 변환(FFT) 연산
* 라이선스: GNU GPL 버전 2 이상

**libpng**
* 용도: PNG 이미지 인코딩
* 라이선스: libpng/zlib 라이선스

**libjpeg-turbo**
* 용도: JPEG 이미지 인코딩
* 라이선스: IJG / BSD 스타일 / zlib

**zlib**
* 용도: 데이터 압축 (libpng의 의존성)
* 라이선스: zlib 라이선스

**libtiff**
* 용도: TIFF 이미지 인코딩
* 라이선스: libtiff 라이선스 (BSD 스타일)

**OpenJPEG**
* 용도: JPEG 2000 이미지 인코딩
* 라이선스: BSD 2-Clause

**libwebp**
* 용도: WebP 이미지 인코딩
* 라이선스: BSD 3-Clause

**libavif**
* 용도: AVIF 이미지 인코딩
* 라이선스: BSD 2-Clause

**libaom**
* 용도: AV1 이미지 인코딩 (libavif의 의존성)
* 라이선스: BSD 2-Clause

**libyuv**
* 용도: 픽셀 형식 변환 및 스케일링 (libavif의 의존성)
* 라이선스: BSD 3-Clause (Google)

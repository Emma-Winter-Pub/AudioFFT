### Bibliothèques principales et d'encodage d'images

**Qt 6**
* Usage : Interface graphique (GUI) et framework multiplateforme
* Licence : GNU LGPL version 3

**FFmpeg**
* Usage : Décodage audio et traitement de flux multimédia
* Licence : GNU LGPL version 2.1 ou ultérieure

**FFTW3**
* Usage : Calcul de la transformation de Fourier rapide (FFT)
* Licence : GNU GPL version 2 ou ultérieure

**libpng**
* Usage : Encodage d'images PNG
* Licence : Licence libpng/zlib

**libjpeg-turbo**
* Usage : Encodage d'images JPEG
* Licence : IJG / De type BSD / zlib

**zlib**
* Usage : Compression de données (dépendance de libpng)
* Licence : Licence zlib

**libtiff**
* Usage : Encodage d'images TIFF
* Licence : Licence libtiff (de type BSD)

**OpenJPEG**
* Usage : Encodage d'images JPEG 2000
* Licence : BSD 2-Clause

**libwebp**
* Usage : Encodage d'images WebP
* Licence : BSD 3-Clause

**libavif**
* Usage : Encodage d'images AVIF
* Licence : BSD 2-Clause

**libaom**
* Usage : Encodage d'images AV1 (dépendance de libavif)
* Licence : BSD 2-Clause

**libyuv**
* Usage : Conversion de format de pixels et redimensionnement (dépendance de libavif)
* Licence : BSD 3-Clause (Google)
